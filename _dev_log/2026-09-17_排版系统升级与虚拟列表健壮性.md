# 2026-09-17 Typography v1 排版系统重塑与虚拟列表健壮性

## 1. 核心改进背景与痛点诊断

在完成基础架构的纯评论流、视口模拟（1180px Compact 模式）和单向下探预读之后，阅读体验暴露出更深层次的视觉失真问题：
1. **行宽与行高比例失调（860px + 14px + 1.38）**：860px 的宽度导致单行中文容纳 50~60 个字，英文接近 100 字符，加上 1.38 的过紧行高，视觉上呈现出强烈的“后台管理表格感/程序界面感”，而非沉浸阅读器。
2. **作者区结构工具栏化**：头像、作者全称、@handle、绝对时间（如本地长日期）多行堆叠并靠右对齐，割裂了社交动态的自然流动感。
3. **网格线条与视觉杂音过多**：Metrics 顶边线、Tweet 底边线、Title 底边线层层堆叠，形成冰冷的网格。
4. **虚拟滚动脱落风险**：推特主时间线采用 React 虚拟列表，快速滑动时基准文章或目标文章节点可能已被卸载脱离 DOM，导致 `compareDocumentPosition` 发生未定义行为或报错。
5. **本地开发配置写死机器路径**：`local-dev.user.js` 写死特定电脑绝对路径，若直接纳入仓库会影响通用性。

## 2. 实施方案与变更对照

### 2.1 Typography v1 排版系统
- **黄金阅读宽度 (Reading Measure)**：
  `.xsr-detail-grid.is-comment-layout .xsr-reply-column` 从 `860px` 降低为 `660px`，两侧辅以 `padding: 0 16px` 与 `margin: 0 auto`。为屏幕两侧留出充分的呼吸空间。
- **正文与行高重塑**：
  - 正文 `.xsr-text`：由 `14px / 1.38` 调整为 `15px / 1.58`，辅以 `-0.01em` 微调字间距，单行行高从 ~19.3px 提升至 ~23.7px，中英文混排阅读质感显著跃升。
  - 主帖正文 `.xsr-tweet.is-prominent .xsr-text`：由 `15px / 1.42` 提升至 `16px / 1.6`。
- **作者 Header 社交化横排**：
  - DOM 结构重构为自然单行流：`[Avatar] [Name (14px/650) · @Handle (12.5px/muted) · Date (11.5px/muted)]`。
  - 引入轻量级相对时间辅助函数 `formatTweetDate`（支持 `just now`、`10m`、`2h`、`3d`、短日期显示），鼠标悬停 `time` 标签保留完整的 `title` 绝对时间提示。
- **减法去网格化**：
  - 彻底移除 `.xsr-metrics` 的 `border-top` 和 `padding-top`，改由 `margin-top: 10px` 自然间距承接。
  - Metrics 排列从生硬的 `space-around` 改为推特原生习惯的 `gap: 24px` 左侧成簇排列。
  - 将推文分隔线淡化为 `color-mix(in srgb, var(--xsr-border) 65%, transparent)`，消除切割感。
- **全局字体栈 (CJK + Latin fallback)**：
  `#xsr-pane` 声明现代跨平台西文与 CJK 回退字体栈：
  `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", "WenQuanYi Micro Hei", sans-serif`。

### 2.2 虚拟列表 DOM 健壮性防线
- 在 `onPointerMove` 下探悬停预读逻辑中，执行 `compareDocumentPosition` 之前严密校验：
  ```javascript
  if (!baselineArticle.isConnected || !article.isConnected) {
    if (!baselineArticle.isConnected) this.scrollTriggeredArticle = null;
    this.clearHoverTimer();
    return;
  }
  ```
  一旦检测到 React 虚拟滚动卸载了先前的基准元素，立即清除引用并退出，彻底杜绝孤立节点判定异常。

### 2.3 Compatibility Adapter 视口边界守卫
- 明确视口伪装（1180px）仅作为与推特前端交互的兼容适配层，本脚本内部所有分栏拖拽、自适应测量一律严格使用 `getRealWindowWidth()`。

### 2.4 本地开发治理
- 新增 `local-dev.user.example.js` 模板，指导开发者复制并在本地配置 `@require file://...`。
- 在 `.gitignore` 中追加 `local-dev.user.js`，避免本地物理路径泄露进版本库。
